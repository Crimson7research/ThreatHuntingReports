Attack Overview

What is Shai-Hulud?

Shai-Hulud (js.shai_hulud) is an npm supply chain worm attributed to threat actor TeamPCP. First observed in May 2026 targeting @antv/TanStack packages, it escalated to the keyv/ChainDrop wave in July-August 2026. The attack compromises popular npm packages by injecting a preinstall hook that downloads the Bun runtime and executes a heavily obfuscated 727 KB JavaScript payload (Math_Symbol.js).

The payload harvests credentials from 140+ file paths across Linux/macOS/Windows, steals cloud secrets (AWS SSM, Secrets Manager, Vault, K8s), and exfiltrates data via multiple channels. The malware resolves its C2 domain dynamically from an Ethereum smart contract (EtherHiding), making domain-based blocklists ineffective. A worm component persists through Claude Code and VS Code IDE configurations and forges Sigstore SLSA provenance attestations.

Attack Chain

1
Initial Access - Package Install
Victim installs a compromised npm package (e.g., keyv@6.0.0) via npm/yarn/pnpm
npm install keyv@6.0.0
2
Execution - Stage 1 Loader
preinstall hook runs setup.mjs which downloads Bun v1.3.13 runtime from github.com/oven-sh/bun
node setup.mjs
3
Payload Deploy - Stage 2
Bun executes Math_Symbol.js (727 KB obfuscated credential harvester + worm). Checks for Russian locale and exits if detected.
bun Math_Symbol.js
4
Credential Harvesting
Scans 140+ credential file paths: SSH keys, cloud credentials (AWS/Azure/GCP), K8s configs, npm/yarn tokens, crypto wallets, messaging apps, VPN configs, CI/CD secrets, AI tool credentials, and shell histories.
5
Cloud Secret Theft
Queries AWS SSM Parameter Store + Secrets Manager across 17 regions, IMDS for IAM credentials, Vault (20+ regex patterns), and K8s service account tokens.
6
EtherHiding C2 Resolution
Resolves exfil domain from Ethereum smart contract (0xE1f2...3103) via 35 hardcoded public RPC endpoints. Attacker rotates domains by updating the contract.
7
Exfiltration
RSA-4096 + AES-256-GCM encrypted data sent via HTTPS POST to C2 /router endpoint and committed to attacker-created GitHub repos (Dune-themed names).
8
Worm Propagation
Infects victim repos via .claude/settings.json and .vscode/tasks.json persistence. Forges Sigstore SLSA provenance attestations to make worm commits appear verified.

KQL Detection Queries

Deploy these queries in Microsoft Sentinel or Defender Advanced Hunting. All queries use a 30-day lookback window. 5 consolidated queries provide full IOC coverage across all known indicators.

3.1 Network-Based Detection

Query #1: C2 Domains + Actor Backend IPs KQL 
// Detect connections to C2 domains and actor infrastructure IPs
let AllThreatDomains = dynamic(["npm-cache.com", "pypi-get.com", "js-mirror.com", "awqhnjewqjkl.icu", "t.m-kosche.com", "telemetry.m-kosche.com", "git-tanstack.com"]);
let ActorIPs = dynamic(["185.95.159.32", "83.142.209.194", "85.137.53.71", "94.154.172.43"]);
DeviceNetworkEvents
| where Timestamp > ago(30d)
| where RemoteUrl has_any (AllThreatDomains)
    or RemoteIP in (ActorIPs)
| project Timestamp, DeviceName, RemoteUrl, RemoteIP, RemotePort, InitiatingProcessFileName, InitiatingProcessCommandLine
| sort by Timestamp desc
Query #2: Node/Bun Infrastructure Abuse (EtherHiding, IMDS, Vault, Exfil) KQL 
// Detect Node/Bun processes contacting Ethereum RPC, IMDS, Vault, exfil endpoints
let EthRPCDomains = dynamic(["go.getblock.io", "securerpc.com", "bitstack.com", "runonflux.io", "chain49.com", "tenderly.co", "diamondswap.org", "lokibuilder.xyz", "publicnode.com", "nodies.app", "unifra.io", "blockpi.network", "linkpool.io", "gateway.fm", "zan.top", "merkle.io", "tokenview.io", "nodeconnect.org", "stateless.solutions", "stackup.sh", "nodifi.ai", "radiumblock.co", "4everland.org", "blockrazor.xyz", "omniatech.io", "0xrpc.io", "owlracle.info", "therpc.io", "stakely.io", "poolz.finance", "pocket.network", "fullsend.to", "swiftnodes.io", "flashbots.net", "mevblocker.io"]);
let DuneRepoNames = dynamic(["prescient", "tleilaxu", "siridar", "powindah", "kralizec", "sandworm", "heighliner", "thumper", "sardaukar", "fremen", "atreides", "melange"]);
DeviceNetworkEvents
| where Timestamp > ago(30d)
| where InitiatingProcessFileName in~ ("bun", "bun.exe", "node", "node.exe")
| where RemoteUrl has_any (EthRPCDomains)
    or RemoteIP in ("169.254.169.254", "169.254.170.2")
    or (RemoteIP == "127.0.0.1" and RemotePort == 8200)
    or (RemoteUrl has "/router" and RemotePort == 443)
    or (RemoteUrl has "api.github.com" and RemoteUrl has_any ("graphql", "user/repos", "user/orgs", "search/commits"))

| project Timestamp, DeviceName, RemoteUrl, RemoteIP, RemotePort, InitiatingProcessFileName, InitiatingProcessCommandLine
| sort by Timestamp desc
