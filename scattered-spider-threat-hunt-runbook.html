Critical Threat Advisory

Primarily English-speaking threat group known for sophisticated vishing and MFA fatigue attacks. Targets help desk personnel to gain initial access, then performs NTDS credential dumping and exfiltrates to MEGA.NZ before deploying BlackCat/ALPHV or DragonForce ransomware. 2025 evolution includes Spectre RAT deployment and technology vendor impersonation via subdomain patterns.

Attack Overview

What is Scattered Spider?

Scattered Spider (UNC3944, Starfraud, Scatter Swine, Muddled Libra) is primarily composed of young adults and teenagers targeting English-speaking organizations across the US, UK, Canada, and Australia. Unlike nation-state APTs, they are financially motivated — seeking extortion through ransomware deployment and data theft.

Their signature capability is social engineering: calling help desk personnel, impersonating employees, and manipulating staff into resetting credentials or installing remote access tools. They are notable for their speed of execution and their ability to abuse legitimate cloud services for data exfiltration. Active since 2022, they have targeted hospitality, telecommunications, financial services, healthcare, and technology MSPs.

Attack Chain

1
Vishing / Help Desk Manipulation
Call target's help desk; impersonate employee; request password reset or remote access tool installation. Attackers research targets via LinkedIn and social media to make impersonation convincing.
2
MFA Fatigue Attack
Bombard target user with MFA push notifications until they approve; or use SIM swap / SS7 interception to capture OTPs. May also use real-time phishing proxies to relay MFA tokens.
3
Initial Authentication
Use reset credentials plus approved MFA to authenticate to cloud services (Azure AD/Entra ID, Okta, VPN). Attackers often register their own MFA device to maintain persistent access.
4
Reconnaissance & Lateral Movement
Enumerate Azure AD/Entra ID; identify privileged accounts; pivot to internal systems via VPN or RDP. Use legitimate admin tools to blend in with normal activity.
5
Credential Dumping via NTDS
Use ntdsutil or Mimikatz to dump Active Directory NTDS.dit; extract all domain credentials. Also use comsvcs.dll via rundll32 to dump LSASS for live credentials.
6
Data Staging & Exfiltration
Compress sensitive data using 7-Zip, WinRAR, or similar tools; exfiltrate to MEGA.NZ (preferred) using its built-in encryption capabilities. Also use Dropbox and other cloud storage.
7
Ransomware Deployment
Deploy BlackCat/ALPHV or DragonForce ransomware for double extortion. 2025 evolution: deploy Spectre RAT for persistent stealthy access even after ransomware incident response.

Impact Assessment

Ransomware Deployment

BlackCat/ALPHV and DragonForce ransomware causing full operational disruption and double extortion

Full AD Credential Compromise

NTDS dump grants access to every account in the domain — complete identity infrastructure takeover

Mass Data Exfiltration

Sensitive data exfiltrated to MEGA.NZ before encryption — enables double extortion leverage

Persistent RAT Access (2025)

Spectre RAT deployment for long-term stealthy access surviving ransomware incident response

KQL Detection Queries

Deploy these queries in Microsoft Sentinel or Defender Advanced Hunting to detect Scattered Spider TTPs. Queries are organized by attack phase. Run P1-Critical queries first.

3.1 Vishing / Social Engineering Detection

Query #1: Suspicious Password Resets Correlated with Remote Tool Installation KQL 
// Scattered Spider: Vishing detection - password resets + remote tool installation
let timeRange = 7d;
let suspiciousResets =
    SigninLogs
    | where TimeGenerated > ago(timeRange)
    | where ResultType == 0
    | where AuthenticationDetails has_any ("ResetPassword")
    | summarize ResetCount = count(),
        UniqueLocations = dcount(Location),
        UniqueIPs = dcount(IPAddress),
        FirstReset = min(TimeGenerated),
        LastReset = max(TimeGenerated)
        by UserPrincipalName
    | where ResetCount >= 3 and UniqueLocations >= 2
    | extend SuspiciousScore = ResetCount * UniqueLocations;
let remoteTools =
    DeviceProcessEvents
    | where TimeGenerated > ago(timeRange)
    | where ProcessCommandLine has_any ("teamviewer", "anydesk", "connectwise",
        "screenconnect", "splashtop")
    | project DeviceName, ProcessCommandLine, TimeGenerated, AccountName;
suspiciousResets
| join kind=inner (remoteTools) on $left.UserPrincipalName == $right.AccountName
| where datetime_diff('minute', LastReset, TimeGenerated) between (0 .. 120)
| project UserPrincipalName, SuspiciousScore, ResetCount, UniqueLocations,
    RemoteTool = ProcessCommandLine
Query #2: Top Password Reset Activity (Admin Account Monitoring) KQL 
// Scattered Spider: Identify top password changers - watch for admin accounts
let timeInterval = 7d;
let signInResets =
    SigninLogs
    | where TimeGenerated > ago(timeInterval)
    | where AuthenticationRequirement has "ResetPassword"
       or AuthenticationDetails has "ResetPassword"
    | project TimeGenerated, User = UserPrincipalName;
let auditResets =
    AuditLogs
    | where TimeGenerated > ago(timeInterval)
    | where ActivityDisplayName has "Reset user password"
        or ActivityDisplayName has "Self-service password reset"
    | extend User = tostring(TargetResources[0].userPrincipalName)
    | project TimeGenerated, User;
union signInResets, auditResets
| summarize ResetCount = count() by User
| order by ResetCount desc

3.2 MFA Fatigue Detection

Query #3: Excessive MFA Challenges Followed by Successful Authentication KQL 
// Scattered Spider: MFA fatigue attack detection
// High volume of MFA challenges followed by eventual success
let timeWindow = 1h;
let mfaEvents =
    SigninLogs
    | where TimeGenerated > ago(7d)
    | where AuthenticationRequirement == "multiFactorAuthentication"
    | where ResultType in (50074, 50076, 0)
    | extend MFAResult = case(
        ResultType == 0, "Success",
        ResultType == 50074, "MFA_Challenge_Declined",
        ResultType == 50076, "MFA_Challenge_Timeout",
        "Other"
    );
mfaEvents
| summarize
    TotalChallenges = countif(MFAResult != "Success"),
    SuccessfulAuths = countif(MFAResult == "Success"),
    FirstChallenge = min(TimeGenerated),
    LastSuccess = max(TimeGenerated),
    UniqueIPs = dcount(IPAddress),
    Locations = make_set(Location)
    by UserPrincipalName, bin(TimeGenerated, timeWindow)
| where TotalChallenges >= 5 and SuccessfulAuths >= 1
| where datetime_diff('minute', LastSuccess, FirstChallenge) <= 60
| extend FatigueScore = TotalChallenges * UniqueIPs
| order by FatigueScore desc

3.3 Credential Dumping

Query #4: NTDS Credential Dumping and Credential Tool Detection KQL 
// Scattered Spider: NTDS credential dumping and Mimikatz detection
let credentialDumpingTools = dynamic(["mimikatz", "procdump", "comsvcs.dll", "ntdsutil"]);
let ntdsAccess =
    DeviceFileEvents
    | where TimeGenerated > ago(7d)
    | where FileName =~ "ntds.dit" or FolderPath has "ntds"
    | where ActionType in ("FileCreated", "FileModified", "FileCopied")
    | project TimeGenerated, DeviceName, FileName, FolderPath,
        InitiatingProcessCommandLine, InitiatingProcessAccountName;
let suspiciousProcesses =
    DeviceProcessEvents
    | where TimeGenerated > ago(7d)
    | where ProcessCommandLine has_any (credentialDumpingTools)
    | project TimeGenerated, DeviceName, ProcessCommandLine, AccountName,
        InitiatingProcessCommandLine;
ntdsAccess
| union suspiciousProcesses
| summarize Events = make_list(pack_all()),
    EventTypes = make_set(strcat(FileName, ProcessCommandLine)),
    FirstSeen = min(TimeGenerated),
    LastSeen = max(TimeGenerated)
    by DeviceName, AccountName
| where array_length(Events) >= 2
| extend RiskScore = array_length(EventTypes) * 10

3.4 Data Exfiltration

Query #5: Large Upload Activity to MEGA.NZ and Cloud Storage KQL 
// Scattered Spider: Data exfiltration to cloud storage, correlated with compression
let cloudStorageServices = dynamic(["mega.nz", "mega.co.nz", "dropbox.com",
    "onedrive.live.com", "drive.google.com"]);
let largeUploads =
    DeviceNetworkEvents
    | where TimeGenerated > ago(7d)
    | where RemoteUrl has_any (cloudStorageServices)
    | summarize
        TotalConnections = count(),
        FirstConnection = min(TimeGenerated),
        LastConnection = max(TimeGenerated),
        UniqueDestinations = dcount(RemoteUrl)
        by DeviceName, InitiatingProcessAccountName, RemoteUrl
    | where TotalConnections >= 10;
let compressionActivity =
    DeviceProcessEvents
    | where TimeGenerated > ago(7d)
    | where ProcessCommandLine has_any ("zip", "rar", "7z", "tar", "gzip")
    | where ProcessCommandLine contains "-r" or ProcessCommandLine contains "archive"
    | project TimeGenerated, DeviceName, InitiatingProcessAccountName, ProcessCommandLine;
largeUploads
| join kind=leftouter (compressionActivity) on DeviceName, InitiatingProcessAccountName
| where datetime_diff('hour', FirstConnection, TimeGenerated) between (-2 .. 2)
| project DeviceName, AccountName = InitiatingProcessAccountName,
    RemoteUrl, TotalConnections, FirstConnection, CompressionCommand = ProcessCommandLine

3.5 Ransomware Detection

Query #6: Rapid File Encryption and Ransomware Process Indicators KQL 
// Scattered Spider: Ransomware deployment detection (BlackCat/ALPHV/DragonForce)
let encryptionExtensions = dynamic([".blackcat", ".alphv", ".encrypted", ".locked", ".crypto"]);
let rapidEncryption =
    DeviceFileEvents
    | where TimeGenerated > ago(1d)
    | where ActionType == "FileModified"
    | where FileName has_any (encryptionExtensions)
        or (FileName contains "readme" and FileName contains "txt")
        or (FileName contains "ransom" and FileName contains "note")
    | extend FileExtension = extract(@"\.([a-zA-Z0-9]+)$", 1, FileName)
    | summarize
        FilesEncrypted = count(),
        FirstEncryption = min(TimeGenerated),
        LastEncryption = max(TimeGenerated),
        UniqueDirectories = dcount(FolderPath),
        Extensions = make_set(FileExtension)
        by DeviceName, InitiatingProcessAccountName, InitiatingProcessCommandLine
    | where FilesEncrypted >= 50 and UniqueDirectories >= 5;
let ransomwareProcesses =
    DeviceProcessEvents
    | where TimeGenerated > ago(1d)
    | where ProcessCommandLine has_any ("blackcat", "alphv", "encrypt", "ransom")
    | where ProcessCommandLine contains ".exe" or ProcessCommandLine contains "powershell"
    | project DeviceName, InitiatingProcessAccountName, ProcessCommandLine, TimeGenerated;
rapidEncryption
| project DeviceName, InitiatingProcessAccountName, FilesEncrypted, FirstEncryption
| union (
    ransomwareProcesses
    | extend FilesEncrypted = 0, FirstEncryption = TimeGenerated
    | project DeviceName, InitiatingProcessAccountName, FilesEncrypted, FirstEncryption
)
| summarize
    TotalEncryptionEvents = sum(FilesEncrypted),
    FirstObserved = min(FirstEncryption),
    LastObserved = max(FirstEncryption)
    by DeviceName, InitiatingProcessAccountName
| extend CriticalAlert = "RANSOMWARE_DETECTED"

3.6 2025 Domain Pattern Detection

Query #7: Technology Vendor Impersonation via Subdomain Patterns KQL 
// Scattered Spider 2025: Subdomain-based domain impersonation of technology vendors
// Detects suspicious SSO/Okta/VPN/helpdesk subdomains on non-legitimate domains
let suspiciousDomains = dynamic([
    "sso.", "okta.", "vpn.", "helpdesk.", "support.",
    "admin.", "portal.", "login.", "auth."
]);
DnsEvents
| where TimeGenerated > ago(30d)
| where Name has_any (suspiciousDomains)
| where not(Name has_any ("microsoft.com", "okta.com", "google.com"))
| summarize DNSRequests = count(),
    FirstSeen = min(TimeGenerated),
    LastSeen = max(TimeGenerated)
    by ClientIP, Name
| where DNSRequests >= 3
| extend RiskScore = DNSRequests * 2
| order by RiskScore desc

3.7 2025 Spectre RAT Detection

⚠ High false positive rate — correlate with other indicators before acting in production environments.

Query #8: Spectre RAT Indicators (Process Injection + Obfuscation) KQL 
// Scattered Spider 2025: Spectre RAT detection - HIGH FALSE POSITIVE RATE
// Use with caution; correlate with other indicators before acting
let spectreIndicators = dynamic(["spectre", "crypter", "obfusc", "inject"]);
DeviceProcessEvents
| where TimeGenerated > ago(7d)
| where ProcessCommandLine has_any (spectreIndicators) or
    FileName has_any (spectreIndicators)
| project TimeGenerated, DeviceName, FileName, ProcessCommandLine,
    AccountName, InitiatingProcessAccountName
| join kind=leftouter (
    DeviceNetworkEvents
    | where TimeGenerated > ago(7d)
    | project DeviceName, RemoteIP, RemotePort, InitiatingProcessFileName
) on DeviceName
| where isnotempty(RemoteIP)
| extend ThreatScore = 85
